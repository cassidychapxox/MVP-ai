# MVP-ai

Movement Vision Performance AI

An AI-powered fitness coach using computer vision and pose estimation to analyze exercise form and provide feedback.

## MVP Goal

The first version will analyze squat form using a mobile camera and return:

- form score percentage
- posture feedback
- improvement suggestions

## Core Features

- Camera-based form analysis
- Squat posture scoring
- AI-generated coaching feedback
- Workout history

## Future Features

- More exercises
- Nutrition tracking
- Protein/calorie guidance
- AI recipe suggestions
- Workout video library
